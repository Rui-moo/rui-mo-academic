# Rui Mo Academic Website

Bilingual academic website for Rui Mo, focused on biomaterials, electrochemical biosensors, functional hydrogel coatings, bio-interfaces, nanoscale molecular transport, and sustainable materials.

## Live site

Once GitHub Pages is enabled, the site will be available at:

<https://rui-moo.github.io/rui-mo-academic/>

## Publishing

The repository includes a GitHub Actions workflow that deploys the static site to GitHub Pages whenever the `main` branch is updated.
